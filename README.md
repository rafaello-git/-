# Практическая работа

В данном репозитории находятся материалы и исходный код для выполнения практической работы.

## Где найти главный файл с решением

Основной файл с кодом и результатами работы называется **`КонечныйКонецХанов(2).ipynb`**.
Практиическая работа под названием рекомендательная система называется ** 'movie_recsys_report.ipynd' **
Практическая рабоота под названием распознование объектов называется ** 'hot-dot.ipynd' **
В данный момент он располагается в директории `data`. 

## 📁 Структура проекта
* `/data/` — папка, содержащая основной код (`КонечныйКонецХанов(2).ipynb`).
* `/notebooks/` — набор данных.
